# Oscar Roofing — Website Specification

This document defines the functional, visual, content,
responsive, SEO, accessibility and technical requirements
for the Oscar Roofing website.

This is an authoritative requirements document.

Any implementation must comply with these requirements unless
the user explicitly instructs otherwise.

# OSCAR ROOFING

## Website Product & Design Specification

### Project Type

Professional responsive static website for a GTA roofing contractor.

### Business

Oscar Roofing

### Domain

oscarroofingcanada.ca

### Primary Objective

Generate qualified roofing inquiries and quote requests while establishing trust and professionalism.

---

# 1. TARGET AUDIENCE

### Residential

Homeowners who need:

* Roof repair
* Roof replacement
* Roof inspection
* Shingle installation
* Emergency repairs
* Skylight work
* Soffit/fascia
* Gutters/eavestroughs
* Attic insulation
* Attic ventilation

### Commercial

Business owners, property managers, contractors and commercial property owners needing:

* Flat roofing
* Roof repairs
* Roof replacement
* Inspection
* Maintenance
* Commercial roofing solutions

---

# 13. MOBILE EXPERIENCE

Mobile is a first-class design target.

Requirements:

* No horizontal scroll
* Sticky/mobile navigation
* Large CTA buttons
* Click-to-call phone
* Simple form
* Stacked service cards
* Optimized images
* Reduced animation
* Fast load time

Consider a mobile bottom action bar:

CALL
GET A QUOTE

if it improves conversion without obstructing content.

---

# 14. ANIMATION SYSTEM

Use subtle:

Fade
Slide
Scale
Hover
Image reveal

Animation duration:

approximately 200–700ms.

No excessive motion.

Support:

prefers-reduced-motion.

Oscar Roofing.

What do they do?
Roofing services.

Where do they work?
GTA.

How do I contact them?
Phone/email.

How do I request a quote?
GET A QUOTE.

The website must make these answers obvious immediately.
